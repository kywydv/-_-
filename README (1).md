# SIPL Language Toolkit

Навчальний інструментарій для мови SIPL: формальна граматика, парсер, AST, інтерпретатор,
trace виконання та CLI. Проєкт реалізує базові конструкції SIPL з посібника М. С. Нікітченка.

## Обрані завдання
CORE-01 (0.5), CORE-02 (1.5), CORE-03 (2.0), CORE-04 (1.0), CORE-05 (1.0),
IDE-03 (2.5), REL-01 (0.5), REL-02 (0.5), REL-03 (0.5). Цільова сума: 10.0 бала.
Статус IDE-03/REL-02/REL-03: див. розділ «Наступні кроки перед здачею» — потрібне
підключення VS Code/GitHub/PyPI та перевірка в середовищі студента.

## Вимоги
- Python 3.10 або новіший
- Для тестів та перевірок: `pip install -e ".[dev]"`

## Встановлення та запуск
```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS:
source .venv/bin/activate

pip install -e .
sipl check examples/power.sipl
sipl run examples/power.sipl --state '{"X":2,"Y":5}'
sipl trace examples/power.sipl --state '{"X":2,"Y":3}'
sipl parse examples/branch.sipl
```

Альтернативно без встановлення entry point:
```bash
PYTHONPATH=src python -m sipl.cli run examples/power.sipl --state '{"X":2,"Y":5}'
```

## Архітектура
- `grammar/SIPL.ebnf` — машинозчитуваний опис синтаксису.
- `src/sipl/lexer.py` — лексичний аналіз і позиції токенів.
- `src/sipl/parser.py` — рекурсивний спуск та Pratt-парсер виразів.
- `src/sipl/ast.py` — власні типізовані вузли AST і SourceSpan.
- `src/sipl/interpreter.py` — виконання операторів, стан змінних і trace.
- `src/sipl/cli.py` — команди `parse`, `check`, `run`, `trace`.
- `tests/` — позитивні та негативні сценарії.
- `.github/workflows/ci.yml` — автоматичні перевірки.

## Синтаксис
Підтримано: цілі числа, змінні, `+`, `-`, `*`, `=`, `>`, `¬`, `∨`,
присвоювання `:=`, композицію `;`, `if-then-else`, `while-do`, `begin-end`, `skip`.

Для усунення неоднозначності зафіксовано пріоритет арифметичних операцій `*` вище `+`/`-`;
бінарні арифметичні операції лівоасоціативні. Для операторів складені гілки/тіла циклів
рекомендується явно брати в `begin ... end`.

## Trace
Події: `BeforeStatement`, `AfterStatement`, `VariableChanged`, `ConditionChecked`,
`ProgramFinished`. Кожна подія містить рядок, колонку, тип оператора, snapshot стану
та додаткові дані.

## Тестування
```bash
pytest
```
Для перевірки покриття:
```bash
pytest --cov=sipl --cov-report=term-missing
```

## Важливі обмеження поточної версії
- SIPL у посібнику має базову БНФ; реалізація не додає функції чи типи поза нею.
- Для булевих виразів реалізовано порівняння, заперечення та диз'юнкцію.
- Початкові значення змінних передаються через JSON-об'єкт `--state`.
- Ліміт кроків захищає від нескінченного виконання.
- Перед остаточним захистом потрібно прогнати тести, перевірити точні правила БНФ із методичкою
  викладача та продемонструвати 2–3 нові SIPL-програми.

## Наступні кроки перед здачею
1. Створити GitHub-репозиторій, запушити код і перевірити CI на GitHub.
2. Підготувати тег `v0.1.0` та GitHub Release з CHANGELOG і wheel/sdist.
3. Для REL-03 опублікувати пакет у PyPI під доступною назвою (потрібен власний акаунт і токен).
4. IDE-03 у повному обсязі потребує DAP-адаптера та VS Code extension; його інтеграцію слід
   окремо завершити й перевірити клавішею F5. Наявне ядро та trace є основою для адаптера.
